# Knitting concept preview

`knitting-concept.html` is a portable, local design presentation for the optional knitting pack. Open it in a browser from this repository; its fonts and original illustrations use relative paths to existing Flutter assets. No build or installation is needed.

The preview contains synthetic values only. It has no ERP/API connection, account login, data persistence or customer access. Company/role choices illustrate the proposed navigation; they are not a permission implementation. Sample QC, delivery and invoice confirmations update local presentation state and reset on reload.

Explore the overview, jobs, job tabs, machine planner, production/QC, delivery/invoice and industry setup. The company selector also shows a business with General ERP only. The reduced-motion control allows inspection without animations; the browser's reduced-motion preference is also respected.

The product architecture, ownership/billing decisions, full-app experience contract and planned real-database checks are in the parent design documents. This HTML is not Flutter product code and does not establish that the knitting workflow is implemented or verified.
